What is a Movement Snack?

A movement snack is a short (2–15 min), intentional physical activity slotted into the gaps of your day — between meetings, after lunch, before bed. Inspired by atomic habits research: small consistent actions compound into lasting change far more reliably than sporadic intense sessions.

➕ How to add a new Movement Snack app

1. Save your new app as a .html file in the SAH_movement_snacks/ folder on GitHub.

2. Open SAH_movement_snacks/index.html in the GitHub editor and copy one of the <a class="app-card" …> blocks.

3. Update the href to your new file name, choose an icon style (icon-orange, icon-violet or icon-green), and fill in the title, description and pills.

4. Commit directly to main — the site updates within 1–2 minutes.
